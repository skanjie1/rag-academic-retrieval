# Data

This directory contains the corpus and evaluation data for the RAG pipeline.

## Data Source

Abstracts are sourced from the [Semantic Scholar API](https://api.semanticscholar.org/) using the following query parameters:
- **Fields**: NLP, Natural Language Processing, Transformers, Language Models
- **Year range**: 2020–2025
- **Corpus size**: 537 abstracts

## Files

- `nlp_abstracts.json` — Raw corpus of paper abstracts with metadata (title, authors, year, venue, abstract)
- `eval_queries.json` — 50 evaluation queries with ground truth answers for RAGAS evaluation
- `faiss_index/` — Serialized FAISS index (generated by `src/ingest.py`)

## Reproducing the Dataset

```bash
python src/ingest.py --fetch --query "natural language processing" --limit 600
```

> **Note**: The raw data files are not included in version control due to size. Run the ingestion script to rebuild from the API.
